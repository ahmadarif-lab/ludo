# Ludo Ledek

Ludo isometrik yang lucu. Karakter yang berdiri di petak aman menjulurkan lidah meledek karena tidak bisa diusir, dan permen di jalan menaikkan peluangmu dapat angka 6.
Main melawan bot atau bareng teman lewat kode room, dengan akun sendiri, riwayat game, dan papan peringkat.

## Main

- **Web**: buka https://ludo.bontot.my.id di browser (HP maupun komputer), lalu daftar akun. Di komputer, tekan **Spasi** untuk melempar dadu.
- **Android**: unduh APK dari halaman [Releases](../../releases/latest).

## Pasang di Android

1. Unduh `ludo-ledek-v1.0.0.apk` dari [Releases](../../releases/latest).
2. Buka berkas yang diunduh. Kalau diminta, izinkan **pasang aplikasi dari sumber ini** untuk browser atau aplikasi File yang kamu pakai.
3. Buka **Ludo Ledek**, lalu daftar atau masuk.

Catatan:
- Butuh Android 7.0 ke atas dan koneksi internet. Ukuran ±1,4 MB, izin hanya `INTERNET`.
- Aplikasi ini belum ada di Play Store dan ditandatangani dengan kunci debug, jadi Play Protect bisa menampilkan peringatan. Itu normal untuk aplikasi di luar Play Store.
- SHA-256 untuk memastikan berkas utuh: `a2f919b4688a211e1c178a89b4ccac26288a9a2b9c5c93c7479d454a15aa557b`
